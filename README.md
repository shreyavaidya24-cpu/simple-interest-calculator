# Simple Interest Calculator

This project is a simple Bash script that calculates simple interest.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Inputs

- `p`: Principal amount
- `t`: Time period in years
- `r`: Annual rate of interest

## Output

```text
simple interest = p*t*r/100
```

## How to Use

Run the script in a Bash terminal:

```bash
bash simple-interest.sh
```

Enter the principal amount, annual interest rate, and time in years when prompted.

## Example

For a principal of 1000, an annual rate of 5%, and a time of 2 years:

Simple Interest = 1000 × 5 × 2 / 100 = 100
